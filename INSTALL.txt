S1x DEBUG OVERLAY - TEST BUILD 0.4 (entity table, unfiltered)
=============================================================

What this does: NOTHING visible. It reads the game's entity list and writes
text files into your game folder. It changes nothing in the game.
This build has NO memory scan and does NOT use F10. Don't press F10.

HOW TO INSTALL
1. Close the game completely.
2. Open the folder "try_this_first". Copy the file inside it (version.dll)
   into your game folder (D:\GAMES\AW). Say YES to replace the old one.
3. Start the game and load a campaign mission.
4. When you can move around, wait about 15 seconds. The add-on saves the
   entity table by itself.
5. Optional: walk somewhere else in the mission and press F9 once for a
   second table.
6. Quit the game. New files in the game folder to send to Claude:
      s1x_debug_overlay.log
      entities_1.txt
      other_raw_1.txt
   (and entities_2.txt / other_raw_2.txt if you pressed F9)

TO UNINSTALL
Delete version.dll from the game folder.
Remove it before playing online, to be safe.
