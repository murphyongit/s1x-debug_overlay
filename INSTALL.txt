Version 0.32 - decoded map entity text (map_ents_0.txt)

Download: https://github.com/murphyongit/s1x-debug_overlay/releases/latest/download/version.dll
Put version.dll in D:\GAMES\AW (replace the old one), start the game, load a mission.

Keys: F8 on/off | F3 next camera source | F4 update-rate test | F5 fov style | F6 thickness | F7 distance
Row of small squares (4th row, top-left) = which camera source is in use.

v0.33: flag triggers (multiple_flag_set etc.) now show the real flag name(s) from the map data, e.g. "flag_set #1854 -> reactor_room_end_combat", in the box label and the IN: panel. The names appear about 10-20 seconds after a mission starts (after the map data file is written).

v0.34: flag triggers are matched to the map data by position, so more of them show flag names.

v0.35: fixed the position matching so most flag triggers show their flag names.

v0.36: when a mission ends the log lists every box entered in the last 2 minutes, with flag names. To find the end trigger: finish a mission, then send the log.

v0.38: triggers whose flag is on the known end list (see KNOWN_END_TRIGGERS.txt) are drawn as rainbow end triggers at any range, and the log and top-right list announce when you enter one.
