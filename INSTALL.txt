S1x DEBUG OVERLAY - TEST BUILD 0.2 (data collection)
====================================================

What this does: NOTHING visible. It only reads the game's memory and writes
text files into your game folder, so we can work out how the campaign stores
triggers. It does not draw anything and does not change the game.

HOW TO INSTALL
1. Close the game completely.
2. Open the folder "try_this_first". Copy the file inside it (version.dll)
   into your game folder (for you: D:\GAMES\AW). Say YES to replace the old one.
3. Start the game the way you normally do and load a campaign mission.
4. Once you can move around in the mission, wait about 15 seconds. The add-on
   takes a dump automatically.
5. Walk to a spot where you know a trigger is (for example a point where a
   scripted event starts when you reach it), stand still, and press F9 once.
   Press F9 again at a second spot if you like (up to 6 dumps in total).
6. Quit the game. In the game folder you will now have these new files:
      s1x_debug_overlay.log
      script_strings.txt
      entity_dump_1.txt   (and entity_dump_2.txt etc. if you pressed F9)
   Send them to Claude.

Only ever have ONE of version.dll / dinput8.dll in the game folder.
(dinput8.dll is only a backup. You will not need it.)

TO UNINSTALL
Delete version.dll from the game folder.
Remove it before playing online, to be safe.
