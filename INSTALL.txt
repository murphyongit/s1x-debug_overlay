S1x DEBUG OVERLAY - TEST BUILD 0.10 (smoother boxes)
========================================================

What this does: draws coloured boxes around the invisible trigger zones in
campaign missions. Campaign only. It does nothing in multiplayer, but remove
it before playing online to be safe.

HOW TO INSTALL
1. Close the game completely.
2. Open the folder "try_this_first". Copy the file inside it (version.dll)
   into your game folder (D:\GAMES\AW). Say YES to replace the old one.

HOW TO TEST
1. Start the game, load a campaign mission, and wait until you can move.
2. Press F8 once. The overlay starts OFF so that loading is never disturbed.
3. You should see small squares in the top-left corner and coloured boxes.
   GREEN = trigger_multiple, RED = hurt, YELLOW = use, ORANGE = radius,
   BLUE = other. A WHITE box means you are standing inside it.

KEYS
   F8  overlay on/off
   F7  how far away to draw (4 choices). Row 1 of squares.
   F5  field-of-view style (3 choices). Row 2 of squares.
   F6  line thickness (3 choices). Row 3 of squares.
   F9  save data files like before (not needed now)

IF THE GAME CRASHES or acts strangely: delete version.dll from the game
folder, and send Claude s1x_debug_overlay.log from the same folder.

TO UNINSTALL
Delete version.dll from the game folder.
