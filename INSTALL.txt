Version 0.32 - decoded map entity text (map_ents_0.txt)

Download: https://github.com/murphyongit/s1x-debug_overlay/releases/latest/download/version.dll
Put version.dll in D:\GAMES\AW (replace the old one), start the game, load a mission.

Keys: F8 on/off | F3 next camera source | F4 update-rate test | F5 fov style | F6 thickness | F7 distance
Row of small squares (4th row, top-left) = which camera source is in use.

v0.33: flag triggers (multiple_flag_set etc.) now show the real flag name(s) from the map data, e.g. "flag_set #1854 -> reactor_room_end_combat", in the box label and the IN: panel. The names appear about 10-20 seconds after a mission starts (after the map data file is written).

v0.34: flag triggers are matched to the map data by position, so more of them show flag names.

v0.35: fixed the position matching so most flag triggers show their flag names.

v0.36: when a mission ends the log lists every box entered in the last 2 minutes, with flag names. To find the end trigger: finish a mission, then send the log.

v0.38: triggers whose flag is on the known end list (see KNOWN_END_TRIGGERS.txt) are drawn as rainbow end triggers at any range, and the log and top-right list announce when you enter one.

v0.39: invisible barriers (brush models named clip/blocker/collision) are drawn hot pink within about 100 m even with Home off, and the top-right list says WALL REMOVED when one disappears. Triggers that set "player_leaving_map" or a death/kill/fail flag are drawn as rainbow warning boxes at any range.

v0.40: first multiplayer version. The add-on now also loads in the multiplayer program (s1_mp64_ship.exe). It works out the multiplayer entity layout itself (see "multiplayer layout" lines in the log). Start a private match with bots, press F8, then press F9 a few times while looking in different directions and send the log and the client_*.txt files.

v0.41: multiplayer camera search. In a multiplayer match press F8; the add-on looks for the game camera by itself (log line "camera search"). If boxes still do not line up, press F3 to try the other camera sources it found.

v0.42: multiplayer layout is re-checked and recalibrated when the map changes.

v0.44: multiplayer boxes now use the correct world positions, and the camera search keeps only the camera copies that follow you after you walk about 3 steps.

v0.45: the log now starts with a big "VERSION NUMBER" banner and the screen shows "OVERLAY v0.45" at the top left when the overlay is on. In multiplayer F9 also writes mp_player_N.txt (raw data about your player) so the camera can be worked out.
