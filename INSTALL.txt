Version 0.32 - decoded map entity text (map_ents_0.txt)

Download: https://github.com/murphyongit/s1x-debug_overlay/releases/latest/download/version.dll
Put version.dll in D:\GAMES\AW (replace the old one), start the game, load a mission.

Keys: F8 on/off | F3 next camera source | F4 update-rate test | F5 fov style | F6 thickness | F7 distance
Row of small squares (4th row, top-left) = which camera source is in use.

v0.33: flag triggers (multiple_flag_set etc.) now show the real flag name(s) from the map data, e.g. "flag_set #1854 -> reactor_room_end_combat", in the box label and the IN: panel. The names appear about 10-20 seconds after a mission starts (after the map data file is written).

v0.34: flag triggers are matched to the map data by position, so more of them show flag names.

v0.35: fixed the position matching so most flag triggers show their flag names.

v0.36: when a mission ends the log lists every box entered in the last 2 minutes, with flag names. To find the end trigger: finish a mission, then send the log.

v0.38: triggers whose flag is on the known end list (see KNOWN_END_TRIGGERS.txt) are drawn as rainbow end triggers at any range, and the log and top-right list announce when you enter one.

v0.39: invisible barriers (brush models named clip/blocker/collision) are drawn hot pink within about 100 m even with Home off, and the top-right list says WALL REMOVED when one disappears. Triggers that set "player_leaving_map" or a death/kill/fail flag are drawn as rainbow warning boxes at any range.

v0.40: first multiplayer version. The add-on now also loads in the multiplayer program (s1_mp64_ship.exe). It works out the multiplayer entity layout itself (see "multiplayer layout" lines in the log). Start a private match with bots, press F8, then press F9 a few times while looking in different directions and send the log and the client_*.txt files.

v0.41: multiplayer camera search. In a multiplayer match press F8; the add-on looks for the game camera by itself (log line "camera search"). If boxes still do not line up, press F3 to try the other camera sources it found.

v0.42: multiplayer layout is re-checked and recalibrated when the map changes.

v0.44: multiplayer boxes now use the correct world positions, and the camera search keeps only the camera copies that follow you after you walk about 3 steps.

v0.45: the log now starts with a big "VERSION NUMBER" banner and the screen shows "OVERLAY v0.45" at the top left when the overlay is on. In multiplayer F9 also writes mp_player_N.txt (raw data about your player) so the camera can be worked out.

v0.46: multiplayer camera now read from the real player data (position and view angles), so boxes should stay in the world.

v0.47: multiplayer camera tuning keys on the number pad (Num1 flips up/down, Num2 flips left/right, Num3 turns the view by 90 degrees, Num4 smoothing on/off). The top left shows the current state: P=pitch sign, Y=yaw sign, T=turn, S=smoothing.

v0.50 - SPEED RUN RECORDER. Records every campaign mission you play into the "speedrun_data" folder
        (positions, triggers entered, events, entities) and saves the game's scripts. See FOR_RUNNERS.txt.

v0.51 - GHOST REPLAY. Put a runner's run file in the game folder as ghost.txt (and optionally a proposed
        route as route.txt). With the overlay on (F8) press Num5 to watch them. Num6 pause, Num7/Num8 slower/faster,
        Num9 restart, Num0 whole path, Num+ / Num- jump 10 seconds. Recorder now saves 10 positions per second.

v0.52 - STANCE DISCOVERY. The recorder now also saves the raw player data (R lines) and a MARK line each time
        you press Insert, so the crouch / jump / slide / hover fields can be found. See the test in the chat.

v0.53 - Marker key is now INSERT (F10 crashed the game). No beep any more.

v0.54 - Marker key is now the NUMPAD * key (Insert is the geometry search key). Recorder: scripts are saved slowly
        in the background (no more stutter at the start), no 30 minute limit, and PERF lines show any slowdowns.

v0.55 - Recorder: the entity scan now runs on its own thread (it was taking 10 seconds per pass and blocking the
        position recording and the marker key). PERF lines now say where the time goes.

v0.56 - Stance: recorded positions now include movement flags, stance and view height; the ghost crouches, lies/slides,
        shows AIR/DASH/SPRINT. Recorder reads memory much faster (the 10 second scan stalls were Windows memory queries).

v0.57 - All memory reads are now fast (the old safety check cost ~19 ms each and stalled the recorder for seconds).

v0.58 - Ghost labels: JUMP, HOVER (slow steady sinking), FALL, DASH (fast while airborne), SLIDE, CROUCH, SPRINT.

v0.59 - Ghost is now a wireframe person (head, torso, walking legs, arms holding a weapon where they look).
        Num/ (numpad divide) = ghost only: hides all triggers, collision and labels.

v0.60 - Recorder keeps ONE file per mission across checkpoint restarts (RELOAD / GAP lines) and records the game clock.
        Ghost: failed attempts are cut out automatically (the game clock going back), all ghost info is top middle with
        GAME and REAL clocks, Num. makes the ghost follow your own game clock.

v0.61 - Ignore the all-zero player reading that appears for one moment during a checkpoint reload (it wrongly cut the whole ghost).
